🎬 Netflix Auto-Login Setup

✅ Automatic Login Enabled!
Once installed, clicking Netflix will automatically log you in using credentials from your .env file.

Step 1: Install Tampermonkey

For Chrome/Edge:

Install Tampermonkey (Chrome)

For Firefox:

Install Tampermonkey (Firefox)

Step 2: Install the Userscript

Click the button below to install the Netflix Auto-Login userscript:

Install Userscript

Or manually copy the URL and paste it in Tampermonkey's "Create new script" page

Step 3: Configure Credentials

Make sure you have set these in your .env file:

VITE_NETFLIX_EMAIL=your-email@example.com
VITE_NETFLIX_PASSWORD=your-password

The app will automatically store these in localStorage when you click Netflix.

Step 4: Test It!

Go back to your app and click the Netflix option. It should automatically:

  1. Open Netflix login page
  2. Fill in your credentials
  3. Click the login button
  4. Log you in automatically!
⚠️ Security Note:
Credentials are stored in browser localStorage and are only used for auto-login. They are cleared after successful login for security.

How It Works

1. When you click Netflix, the app reads credentials from .env

2. Credentials are stored in localStorage

3. Netflix page opens

4. Userscript detects the login page and reads credentials from localStorage

5. Userscript automatically fills the form and submits

6. You're logged in! 🎉

Troubleshooting

Auto-login not working?

  • Make sure Tampermonkey is installed and enabled
  • Check that the userscript is installed and enabled in Tampermonkey dashboard
  • Verify credentials are set in .env file
  • Check browser console (F12) for any errors
  • Make sure popups are allowed for the site
