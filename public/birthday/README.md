# Birthday photos

Images are set from WhatsApp uploads in `public/`:

- `hero.jpg` — top banner (newest photo)
- `day-01.jpg` … `day-24.jpg` — one per calendar day
- Day 24 finale shows all 24 in a collage grid

To replace: overwrite these files or drop new WhatsApp images in `public/` and re-run copy script.

Password: DOB format — see `src/data/birthdayCalendar.js`
